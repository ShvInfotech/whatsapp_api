GET POST /api/send ⭐ SendBuddy Compatible Dispatch API

Send WhatsApp messages directly from VB.NET, C#, Python, or PHP without changing your software's URL structure.

Standard HTTP URL / Request:
GET /api/send?number=919876543210&type=text&message=Hello+World&instance_id=679B485A1510B&access_token=679b262160af7
Parameters:
  • number: Recipient mobile number with country code (e.g. 919876543210)
  • type: Message type (text)
  • message: Text message content (URL-encoded)
  • instance_id: Your WhatsApp client instance ID
  • access_token: Your client security token
Desktop Software (VB.NET / C#) Example:
Dim url As String = "http://93.127.198.184/whatsapp_api/api/send?number=" & strMobileNo & "&type=text&message=" & strMessage & "&instance_id=" & strInstance & "&access_token=" & strToken
Success Response (200 OK):
{
  "status": "success",
  "message": "Message sent successfully",
  "data": {
    "id": "false_919876543210@c.us_3EB0...",
    "to": "919876543210",
    "timestamp": 1758450000
  }
}
POST /api/auth/login Admin login; creates the protected dashboard session

This public endpoint sets the HTTP-only admin session required by every WhatsApp API.

Request Body:
{
  "username": "admin",
  "password": "your-password"
}
POST /api/auth/forgot-password Verify recovery details and update the admin password in JSON

Verifies username, email and recovery code. The new password hash is dynamically saved in data/admin.json.

Request Body:
{
  "username": "admin",
  "email": "admin@safevault.local",
  "recoveryCode": "your-recovery-code",
  "newPassword": "minimum-8-characters"
}

Security: recovery code and password are never returned by the API.

GET /api/status Check connection status & device details

Returns the current status of the WhatsApp client (`CONNECTED`, `AUTHENTICATING`, `QR_READY`, `DISCONNECTED`).

POST /api/send-bulk Send bulk messages with anti-ban delay (4-5s)
Request Body (Option A - Same message to all):

  "phoneNumbers": [
    "918140349408",
    "919727899812"
  ],
  "message": "Safe Vault scheduled notification.",
  "options": {
    "minDelayMs": 3500,
    "maxDelayMs": 5000
  }

    ]
  }

Cleans `.wwebjs_auth` cache, closes browser, and generates a fresh pairing QR code.
